# Configs Directory

This folder holds configuration files (YAML or JSON) to separate implementation from hyperparameter tuning.

## Structure

- `model_config.yaml`: Architecture settings (e.g., embedding size, number of layers, attention heads, context window).
- `training_config.yaml`: Hyperparameters for training (e.g., learning rate, batch size, epochs, optimizer settings).
- `api_config.yaml`: FastAPI deployment settings.
